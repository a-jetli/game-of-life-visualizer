Simple visualizer for John Conway's Game of Life.

You can read more about it on its Wikipedia page, including the rules of the game: [Conway's Game of Life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life)

## Keyboard shortcuts

- `Left Arrow` / `J` -- step back in history
- `Space` / `K` -- play / pause
- `Right Arrow` / `L` -- step forward
- `,` / `-` -- decrease playback speed
- `.` / `=` -- increase playback speed

## Mouse controls

- `Left Click` / `Drag` -- draw or erase cells (drawing mode only)
- `Right Click` / `Drag` -- pan the view
- `Scroll` -- zoom in / out


The playable grid is bounded at 500x500 pixels. You can modify the grid any time its paused.
